## Ejecutar el portafolio localmente

### Requisitos
- Node.js
- npm

### Instalación

Clonar el repositorio:

```bash
git clone https://github.com/JohanRRod/mi-portafolio.git
```

Entrar al proyecto:

```bash
cd mi-portafolio
```

Instalar dependencias:

```bash
npm install
```

Iniciar el servidor:

```bash
npm run dev
```

Abrir la dirección local indicada en la terminal.
